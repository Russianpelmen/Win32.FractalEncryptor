# Win32.FractalEncryptor
The cryptographer uses a modified version of XOR encryption

- The program has the following functionality:
  - Key generation using PRNG Xorshift128
  - File encryption and decryption
  - There is a window
  - Key verification
  - During assembly, the file is compressed using UPX
