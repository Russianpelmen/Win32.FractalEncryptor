# Win32.FractalEncryptor
Шифровальщик использует модифицированную версию XOR шифрования

- Программа имеет следующий функционал:
  - Генерация ключа при помощи PRNG XorShift128
  - Шифрование и дешифрование файлов
  - Имеется окно
  - Проверка ключа
  - При сборке файл сжимается при помощи UPX
